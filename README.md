# Agentic Analytics with Claude Code

Official course repository for the O'Reilly Online Live Training course [**Agentic Analytics with Claude Code**](https://www.oreilly.com/live-events/agentic-analytics-with-claude-code/0642572404420/).

## Getting started

1. Download this repository as a ZIP file.
2. Extract the ZIP file.
3. Move the course materials out of the repository folder—for example, to your desktop.
4. Delete this `README.md` file so Claude Code does not mistake it for part of the course materials.
